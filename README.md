
# Offline Face Authentication System

Offline-first facial authentication system with liveness detection for Android and iOS devices.

## Features
- Offline face recognition
- Liveness detection
- React Native mobile app
- Lightweight AI models
- Fast authentication
- Local storage with cloud sync

## Tech Stack
- Python
- TensorFlow Lite
- React Native
- Flask
- OpenCV
- MediaPipe
