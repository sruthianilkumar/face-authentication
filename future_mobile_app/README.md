# Future Mobile App

React Native (Expo) mobile client for the Offline Face Authentication System.

## Features

* Camera access using Expo Camera
* Face image capture
* Communication with Flask backend API
* Authentication result display

## Run

```bash
npm install
npx expo start
```

## Backend

Ensure the Flask backend is running before testing authentication requests.

Default API endpoint:

http://<SERVER_IP>:5000/auth
